# 🏎️ PITWALL – GP de São Paulo

## 📌 Sobre o projeto

O **PITWALL – GP de São Paulo** é um projeto desenvolvido como atividade prática da disciplina de LIMA, com o objetivo de recriar uma página temática sobre o Grande Prêmio de São Paulo, realizado no Autódromo de Interlagos.

O site apresenta informações sobre os pilotos, classificação, equipes e ingressos, utilizando apenas **HTML5 e CSS3**, sem JavaScript.

## 🎯 Objetivo da atividade

Praticar os conhecimentos de HTML e CSS por meio da criação de uma página web, trabalhando a organização dos elementos, estilização, posicionamento e responsividade.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo da página.
- **CSS3:** estilização, cores, fontes e layouts.
- **Google Fonts:** utilização da fonte Titillium Web.
- **Flexbox:** organização do cabeçalho, banner e filtros.
- **CSS Grid:** organização dos cards dos pilotos e formulário.
- **Media Queries:** adaptação da página para dispositivos móveis.

## 🏁 Funcionalidades e seções

- **Cabeçalho:** logotipo e menu de navegação.
- **Banner principal:** apresentação do GP de São Paulo e informações do circuito.
- **Grid de pilotos:** cards com nomes, números e equipes.
- **Classificação:** tabela com posições, vitórias, diferenças e pontuação.
- **Ingressos:** apresentação dos setores e respectivos preços.
- **Formulário:** campos visuais para informações de reserva.
- **Rodapé:** identificação do projeto e autoria.

## 🎨 Recursos visuais

- Variáveis CSS (`:root`) para definição das cores.
- Cores inspiradas nas equipes de Fórmula 1.
- Imagem de fundo do piloto.
- Efeito visual de zebra da pista.
- Fonte Titillium Web importada do Google Fonts.
- Layout adaptável para computador e celular.

## 📱 Responsividade

O projeto utiliza `@media` para adaptar a apresentação dos elementos em diferentes tamanhos de tela, permitindo a visualização tanto em computadores quanto em celulares.
